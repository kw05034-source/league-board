# 리그전 기록판 (탁구)

학생이 클래스룸 링크로 들어와 경기 점수를 입력하고, 조별 순위가 바로 계산되는 웹입니다.
코드는 GitHub에, 학생 이름과 기록은 구글 시트에만 있습니다. 이 저장소에는 학생 이름이 없습니다.

```
tt/            3학년 탁구 화면 (index.html, config.js)
common/        화면 공통 코드 (league.js, league.css)
apps-script/   구글 시트에 붙여넣는 서버 코드 (Code.gs)
```

## 처음 설치 (30분 안팎)

### 1. 구글 시트와 서버 코드
1. 구글 드라이브에서 새 스프레드시트를 만들고 이름을 `3학년 탁구 리그전`으로 합니다.
2. 메뉴 `확장 프로그램 > Apps Script`를 엽니다.
3. 기본으로 있는 코드를 모두 지우고 `apps-script/Code.gs` 내용을 붙여넣은 뒤 저장합니다.
4. 시트 화면으로 돌아와 새로고침하면 메뉴에 `리그전`이 생깁니다. `리그전 > 시트 준비하기`를 누르고 권한을 허용합니다. (처음에는 "확인되지 않은 앱" 안내가 나오는데, 고급 > 이동을 누르면 됩니다.)
5. `Students` 탭 A1 칸을 선택하고 3학년 명렬(`roster_3.csv` 내용)을 붙여넣습니다. 열 순서는 학년, 반, 번호, 이름, 성별입니다.
6. `Config` 탭에서 **교사코드**를 확인합니다. **학생코드는 비워 두면** 학생이 코드 없이 들어오고, 숫자를 적으면 학생도 그 코드를 입력해야 들어옵니다.

### 2. 웹앱으로 배포
1. Apps Script 화면에서 `배포 > 새 배포 > 유형: 웹 앱`.
2. 실행 사용자는 `나`, 액세스 권한은 `모든 사용자`로 선택하고 배포합니다.
3. 나오는 웹 앱 URL(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
4. `tt/config.js`를 열어 `api:` 뒤의 `PASTE_APPS_SCRIPT_URL_HERE`를 그 주소로 바꿉니다.

`Code.gs`를 수정한 뒤에는 `배포 > 배포 관리 > 수정 > 새 버전`으로 다시 배포해야 반영됩니다.

### 3. GitHub Pages로 올리기
1. 내 GitHub 계정에 새 저장소(예: `league-board`)를 만들고 이 폴더의 파일을 모두 올립니다.
2. 저장소 `Settings > Pages`에서 Branch를 `main`, 폴더를 `/ (root)`로 저장합니다.
3. 몇 분 뒤 `https://내계정.github.io/league-board/tt/` 에서 열립니다.
4. 무료 계정은 공개 저장소에서만 Pages가 되는데, 학생 이름이 코드에 없어서 공개해도 됩니다. 다만 `config.js`에 들어간 Apps Script 주소는 공개됩니다. 학생코드를 비워 두면 그 주소를 아는 사람은 누구나 학생 이름을 볼 수 있으니, 필요하면 `Config` 탭에 학생코드를 적으세요.

### 4. 클래스룸에 올리기
`.../tt/` 링크를 올립니다. 학생코드를 정했다면 함께 올리고, 교사코드는 올리지 마세요.

## 수업에서 쓰는 순서
1. 화면 위쪽의 `교사 입장`에서 교사코드로 들어가 `교사 관리`에서 반을 고르고 `조 편성하기`를 누릅니다. 반마다 합니다. 조는 `조 수`로 정합니다(1이면 전원이 한 조, 한 조는 최소 2명). `남녀 따로`를 고르면 `남 조 수`와 `여 조 수`를 각각 정합니다. 
2. 학생은 링크로 들어와 자기 이름을 고르고, 조의 경기에 점수를 입력합니다.
3. 점수는 입력하면 바로 시트(`Scores` 탭)에 저장되고, 입력한 사람과 시각이 남습니다. 모든 변경은 `Log` 탭에 쌓입니다.
4. **조를 다시 편성하면** 그 반의 점수가 화면에서는 지워지지만, 지워지기 전에 `Backup` 탭에 보관됩니다(백업시각, 이전 조, 왼쪽·오른쪽 학생 이름, 점수, 입력자). 점수를 확정한 경기가 있으면 다시 편성할 수 없으니 먼저 `확정 해제`를 눌러야 합니다. 편성 화면에는 지워질 점수 개수가 표시됩니다.
5. 끝난 반은 `교사 관리 > 점수 전체 확정`으로 잠글 수 있습니다. 확정한 경기는 학생이 고칠 수 없고, 교사는 고칠 수 있습니다.
6. 순위표 탭은 수업 중에 큰 화면에 띄우기 좋습니다.

## 동시 접속에 대해
화면은 30초마다 자동으로 새로고침하고, 서버는 읽기 결과를 20초 동안 캐시합니다. 학생 100명이 동시에 써도 구글 Apps Script의 하루 실행 시간 한도 안에서 쓸 수 있게 한 설정입니다. 점수를 입력하고 있는 칸이 있으면 그 화면은 자동 갱신을 잠시 건너뜁니다.

## 내년에 다시 쓰기
1. 구글 시트에서 `파일 > 사본 만들기`로 복사합니다.
2. 사본의 `Students` 탭을 새 명렬로 바꾸고, `Groups`, `Scores`, `Log` 탭은 1행(제목)만 남기고 지웁니다.
3. 사본의 Apps Script를 새로 배포하고, `tt/config.js`의 주소를 바꿔 GitHub에 올립니다.
4. `Config` 탭의 코드를 새로 정합니다.

## 참고
- 명렬 수정(전학, 이름 정정)은 `Students` 탭에서 바로 합니다. 이미 편성한 조에 반영하려면 그 반을 다시 편성해야 합니다.
- 개별 경기를 잠그거나 풀려면 `Scores` 탭의 `확정` 칸에 `확정`이라고 쓰거나 지웁니다.
- 순위 규칙은 승점, 세트 득실, 점수 득실, 팀 번호 순입니다.
